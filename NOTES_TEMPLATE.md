# Notes Template

Template and specification for the onion-peeling literature guide and research notes.

## Onion-Peeling Literature Guide (剥洋葱式文献导读)

This section is always placed at the very top of notes.md, before any other content.
It must NOT appear in full.md or in a separate third file.

### Step 1: Full Absorption and One-Sentence Summary (Context / 全盘吸收与一句话总结)

- After reading the entire paper, distill the core motivation
- One sentence explaining "what real-world problem does this solve?"
- Must be concrete — not a restatement of the paper title

### Step 2: Build Intuition with Everyday Metaphor (Grounding / 构建直觉与生活隐喻)

- Set aside academic jargon entirely
- Use a vivid everyday scenario: water pipe splitting, cake cutting, library lending, package sorting, restaurant queuing, etc.
- The metaphor must cover the paper's main operating logic, not just a peripheral phenomenon

### Step 3: Core Equation Deconstruction (Core Focus / 聚焦核心公式拆解)

- Select 1–2 equations that best represent the paper's mechanism
- Map each key symbol to the everyday metaphor from Step 2
- Explain in plain language what each symbol represents in the real-world scenario
- Describe the physical, logical, or optimization meaning of these equations

### Step 4: Exhaustive Sweep and Completion (Exhaustive Mapping / 全盘扫荡与补全)

- After the core logic is clear, progressively integrate remaining equations, auxiliary definitions, and derivation steps
- Explain what role each plays in the overall method
- Frame these as "completing the main story," not starting a new one

### Constraints

- Tone: explanatory, not academic abstract restatement
- Metaphors must be genuinely understandable — do not explain jargon with more jargon
- Core equations: strictly 1–2 only, avoid turning this into an equation catalog


The notes file serves research judgment — it should not repeat the full translation. Include:
- Paper metadata
- One-sentence core problem
- Method overview
- Main contributions
- Key experimental findings
- Key formulas or mechanisms
- Strengths and limitations
- Relevance to current research topics
- Follow-up questions worth pursuing
